# ÇAY FALI MOTORU - RESMİ DOKÜMANTASYON

Bu repository, insanlığın en büyük sorunu olan "çay falı tutar mı?" sorusuna bilimsel ve kesin cevap vermek üzere kurulmuştur.

## Nasıl Çalışır?

1. Çayını içersin.
2. Bardağı ters çevirirsin.
3. Bu motoru çalıştırırsın.
4. Motor, bardağının dibindeki şekilleri quantum düzeyde analiz eder (gerçekte rastgele seçer).
5. Hayatın değişir.

**UYARI:** Bu motor çalışırken çay soğursa motor çöker ve tüm evren yeniden başlar. Dikkatli kullanın.

## Kurulum

```bash
pip install -r requirements.txt  # Boş, ama olsun
python cay_fali.py
```
